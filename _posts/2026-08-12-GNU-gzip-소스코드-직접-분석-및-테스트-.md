## gzip과 tar를 실행흐름으로 이해하기

```
gzip
 ├─ 프로그램
 │    └─ GNU gzip
 │
 └─ 파일 포맷
      └─ RFC 1952
           │
           ├─ gzip Header
           │
           ├─ DEFLATE compressed stream
           │      │
           │      ├─ LZ77
           │      └─ Huffman Coding
           │
           └─ Trailer
                  ├─ CRC32
                  └─ ISIZE
```

```
원본 데이터 -> LZ77 -> Huffman Coding -> DEFLATE stream
-> gzip 
```
